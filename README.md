# Deep Research AI Agent
## 📌About the Project 
Deep Research AI Agent is an AI-powered research assistant designed to make online research easier and more efficient.

Built with Python and Flask, the application searches the web for
relevant information, analyzes content, and generates concise research
summaries using locally running AI models through Ollama. It also
supports image analysis and provides a user-friendly interface
developed with HTML, CSS, and JavaScript.

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **AI Models:** Ollama (Phi-3 and LLaVA)
- **Web Search:** DuckDuckGo Search
- **Libraries:** Beautiful Soup, Requests
